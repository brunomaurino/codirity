## Inherited by whatever comes next

- **A mass-reformatting regex is not a refactor.** W6's sweep changed ~1,700 lines to delete ~95
  classes, and the noise HID two real regressions (commented-out class arrays, an eaten JSX space)
  that tsc, eslint and the build all passed. Sweep line by line, never touch comment lines, and
  never normalise whitespace as a side effect. A 1:1 diff is the thing that makes review possible.
- **Tailwind v4 scans the WHOLE project**, so a class name quoted in prose — in `docs/`, in a
  `notes.md`, in a code comment — regenerates that utility. This is why the sweep's first pass
  "finished" with ~70 dead utilities still shipping. `@source not "../../docs"` is the fix;
  `@custom-variant dark` stays as the belt to that braces.
- **The two sections the plan never gave a bundle to are still v3:** `Benefits` (a card grid with
  `SectionHeader`/`AccentWord`) and `ContactForm` (a white card with the v3 green gradient accent
  bar, sitting beside the mint close CTA — two action greens visible together). Both work, both are
  measured AA, neither matches the v4 system. They are the honest remaining scope.
- **`AccentWord`, `SectionHeader`, `Card`, `Input`, `Select`, `Button`** survive only because those
  two sections consume them. Rework or retire the sections and these go with them.
