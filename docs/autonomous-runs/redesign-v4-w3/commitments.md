## Target: redesign-v4 Bundle W4

(none as deferrals — awareness:)

- **`.d-*` classes set font-size ONLY.** A display heading is `class="display d-md"` — `.display`
  carries the leading and tracking. W3 shipped the heading without it and the block rendered ~65%
  taller. The type-scale banners in `docs/design-system.md` and `CLAUDE.md` read as if `.d-*` were
  complete, which is plausibly what caused it; both are now corrected, but **check any new heading
  against the mockup's full class list, not just its size class.**
- **Opacity COMPOUNDS, and a dimmed-but-readable state should be a colour.** `.is-shipped`'s
  `opacity: .35` multiplied with the status word's own `.7` down to 1.7:1. `--chalk-faint`
  (`#7E8D85`) is the new recessive-but-readable tier on the dark ground — use it instead of stacking
  opacity on text. W4's case-study cards have the same shape of "de-emphasised but still read" state.
- **A flex item with `margin-inline: auto` shrink-wraps to min-content.** The mockup patches this
  for its hero (`.hero > .wrap { width: 100% }`) and W3 hit it again on the queue stage. **Any
  `.wrap-v4` inside a flex container needs `width: 100%`** or the page gutter silently stops
  matching the rest of the site.
- **Measure contrast by compositing the FULL opacity chain**, not by reading the declared colour.
  The helper used here walks every ancestor's opacity and composites over the real ground; a
  declared-colour check would have reported the shipped chip as passing.
